# PAYMENT_FLOW: جریان پرداخت و تبدیل به ریال

هدف: شرح جریان پرداخت با Stripe (یا provider دیگر) و نحوه اتصال به صرافی/پرداخت‌یاری برای تبدیل به ریال و واریز به حساب بانکی.

1) خرید اعتبار/پلان در داشبورد
- کاربر در داشبورد محصول/پلان را انتخاب می‌کند و به صفحه پرداخت هدایت می‌شود.
- از Stripe Checkout یا API استفاده می‌کنیم (sandbox برای تست).

2) وبهوک پرداخت
- Stripe وبهوک POST به /api/webhooks/payments ارسال می‌کند.
- backend ترکنش را تأیید، رکورد مالی می‌سازد و وضعیت اشتراک/اعتبار را بروزرسانی می‌کند.

3) تبدیل به ریال و واریز
- پیشنهاد: اتصال فنی به یک صرافی یا PSP محلی که API دارد (مثلاً یک service exchange)
- flow پیشنهادی:
  - هنگام نیاز به تبدیل، backend یک سفارش تبدیل به صرافی ارسال می‌کند (API).
  - صرافی پس از تأیید، مبالغ را به حساب بانکی دریافت‌کننده واریز می‌کند و callback به ما می‌دهد.
  - سپس we record transaction and send receipt to user.

4) اعلان و رسید
- پس از تأیید واریز، سیستم یک email + SMS شامل لینک رسید و اسکرین‌شات تولید شده توسط puppeteer ارسال می‌کند.

نکات حقوقی
- همکاری با صرافی نیاز به رعایت قوانین محلی و KYC دارد.
- ذخیره اطلاعات مالی به‌صورت امن و رمزگذاری شده ضروری است.
